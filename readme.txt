========================================================================
               学习通自动播放（图像识别版） 使用说明书
========================================================================

一、这是什么
------------------------------------------------------------------------
这是一个用“图像识别 + 模拟真人鼠标点击”来自动观看学习通课程视频的
桌面小程序。程序不会读取网页源码、不使用浏览器调试接口、不修改网页
数据，它的工作方式和真人完全一样：
    看屏幕 → 认出目录和播放进度条 → 用鼠标点一下 → 继续看屏幕

配套文件：
    学习通自动播放.exe      ← 双击运行（桌面）
    readme.txt              ← 本说明（桌面）
    源程序（Python，面向对象编写）在工作目录 xxt-autoplay 文件夹中。

------------------------------------------------------------------------
二、运行前准备（重要）
------------------------------------------------------------------------
1. 用 Microsoft Edge 打开学习通课程播放页，标题里应能看到
   “学生学习页面”，页面上有视频、右侧有“目录/讨论/笔记/标注”。
2. 请提前登录好学习通，并让页面停留在你要开始播的那一节。
   程序会从“目录里当前高亮（浅蓝色）的那一行”开始往下播。
3. 浏览器窗口不需要手动最大化，程序会自动把它最大化并放到最前面。
4. 程序运行期间：
   · 请不要移动鼠标、不要敲键盘、不要点击别的窗口；
   · 不要让浏览器窗口最小化或被遮挡；
   · 不要用 Win+L 锁屏、不要让电脑进入睡眠（建议临时关闭睡眠）。
5. 运行结束、或你想中途停止：按键盘上的 Esc 键即可安全退出。
6. 系统要求：Windows 10 / Windows 11（自带“简体中文”OCR 识别组件，
   本机已具备，无需额外安装任何东西）。

------------------------------------------------------------------------
三、怎么用（三步）
------------------------------------------------------------------------
第 1 步：双击桌面上的“学习通自动播放.exe”。
第 2 步：出现黑色控制台窗口后，会显示 6 秒倒计时（按 Esc 可取消）。
        倒计时结束后程序自动开始工作，鼠标会自己移动，请不要抢鼠标。
第 3 步：程序结束时窗口会显示播放汇总，按一下回车键关闭窗口即可。

运行过程中，控制台会持续打印日志，例如：
    [OK]   视频播放中：3:20 / 12:13
    [INFO] 进度 41.2%  5:02 / 12:13  已用时 6分12秒
    [OK]   本节已播完（进度 95.1%），用时 12分3秒
    [INFO] 点击「下一节」按钮
    [OK]   已切换到：1.17 中国国防历史的主要启示（上）

------------------------------------------------------------------------
四、它是怎么判断“该切下一节”的
------------------------------------------------------------------------
程序同时用两种方式判断播放进度，任何一个达到 95% 就自动切下一节：
1. 识别播放器右下角的“当前时间 / 总时长”（例如 0:04 / 12:13）；
2. 识别进度条上蓝色已播放部分占据的比例。
说明：学习通规定“观看时长 ≥ 总时长的 90%”即算完成，程序默认用 95%
来留出安全余量。想改成别的比例，见第七节“参数调整”。

切换下一节的方式（按优先级）：
1. 先点页面底部的蓝色「下一节」按钮；
2. 如果按钮没有了，就在右侧目录里点当前章节的下一行；
3. 如果目录当前看不到下一行，就自动把目录向下滚动，继续找；
4. 一直找到目录最后一行还没有下一节，就认为整个课程播完，自动结束。

------------------------------------------------------------------------
五、弹窗与章节测验怎么处理
------------------------------------------------------------------------
· 普通提示弹窗（例如“确定 / 知道了 / 继续观看 / 关闭”等）：
  程序能识别出来，并自动点击对应按钮把弹窗关掉，然后继续播放。
· 视频播放中突然弹出“章节测验/弹题”（单选题、多选题等）：
  程序会暂停自动化，并在控制台提示：
      “请在浏览器中手动完成章节测验；完成后程序会自动继续。”
  你手动做完测验后，程序会自动检测到测验页面消失并继续；
  如果长时间没有自动继续，也可以在控制台窗口按一下回车键。
  （这样做是为了不乱选答案，避免影响你的成绩。若希望程序自动
    关掉弹题窗口，可修改 config.json 里的 prompt_quiz 为 false。）

------------------------------------------------------------------------
六、声音与倍速
------------------------------------------------------------------------
· 程序启动时会自动把系统音量设为“静音”，退出时恢复原来的静音状态。
  如果你希望有声音，把 config.json 里的 mute_when_possible 改成 false。
· 播放速度保持原速 1.0 倍，不修改倍速（避免被平台判定异常）。
· 页面上的任何按钮都是靠“图像识别 + 鼠标点击”完成的，没有任何
  脚本注入、接口调用或修改网页数据的操作。

------------------------------------------------------------------------
七、参数调整（一般不需要改）
------------------------------------------------------------------------
第一次运行后会自动生成配置文件：
    C:\Users\你的用户名\AppData\Local\XxtAutoPlay\config.json
用记事本打开即可修改，改完保存，重新运行程序生效。常用字段：

  completion_ratio     完成判定比例，默认 0.95（即 95%）
  ocr_interval         多久做一次完整文字识别（秒），默认 7
  poll_interval        进度轮询间隔（秒），默认 1.0
  mute_when_possible   是否自动静音，默认 true
  prompt_quiz          遇到章节测验是否暂停等人工，默认 true
  start_chapter        指定起始章节号，例如 "1.16"（默认空=从高亮行开始）
  max_chapters         最多播几节（0=不限制，调试时可填 1）
  dry_run              只识别不点击，默认 false
  verify_delay         每次点击后等待多久再识别校验（秒），默认 1.0
  motion_threshold     画面变化比例超过多少算“视频真的在动”，默认 0.06
  confirm_play_attempts  确认“真的在播放”最多点几次，默认 6
  resume_enabled       是否启用断点续播（下次启动接着上次章节），默认 true

日志和出错截图保存在：
    C:\Users\你的用户名\AppData\Local\XxtAutoPlay\logs\日期时间\
其中 run.log 是文字日志，出错时的截图也在这个目录里。

------------------------------------------------------------------------
八、调试与自检（可选）
------------------------------------------------------------------------
打开控制台（Win+R 输入 cmd 回车），进入 exe 所在目录后可以：

  学习通自动播放.exe --dry-run
      只截屏识别当前页面并打印结果，不会动鼠标。
      用来确认程序能不能正确认出你的页面（请先把学习通窗口放到前台）。

  学习通自动播放.exe --image  截图文件路径
      离线识别一张截图，输出识别结果和标注图，适合排查问题。

  学习通自动播放.exe --start 1.16
      从指定章节开始播放。

  学习通自动播放.exe --max-chapters 1
      只播 1 节就停，适合先小范围试跑。

  学习通自动播放.exe --reset-resume
      清除“断点续播”记录，强制从页面当前章节开始。

九、常见问题
------------------------------------------------------------------------
问：提示“没有找到学习通页面所在的浏览器窗口”怎么办？
答：确认用的是 Edge，页面标题包含“学生学习页面”，并且没有最小化。
    程序会等待 60 秒左右，期间打开页面即可自动继续。

问：能看到进度但一直不切下一节？
答：看看日志里的进度是否在增长。如果一直是同一个数字，说明视频被
    暂停了：程序会自动点一次播放键/画面尝试恢复；若仍不行，请手动点
    一下播放，程序会继续监控（也可以用 --dry-run 先确认识别是否正常）。

问：程序点了“下一节”但页面没反应？
答：程序会自动改点右侧目录里的下一行，并把目录向下滚动继续找；
    如果仍然失败会重试并输出日志截图，你可以把截图发给开发者。

问：目录里章节很多，课程没播完程序就停了？
答：检查目录是否已经滚到底（3~6 章节的课程比较短，可能确实播完了）；
    日志最后会打印“已经是本课程的最后一节”。

问：想中途停下来？
答：按 Esc。程序会立即停止模拟操作，并恢复音量。

问：会不会被平台判定为作弊？
答：程序只做“看屏幕 + 模拟鼠标点击”，不会修改网页、不破解接口、
    不改倍速；但任何自动化工具都无法保证平台规则，请自行评估使用风险，
    并优先用于自己确实需要完成的学习任务。

十、卸载
------------------------------------------------------------------------
1. 删除桌面上的“学习通自动播放.exe”和本 readme.txt；
2. 删除目录 C:\Users\你的用户名\AppData\Local\XxtAutoPlay
   （里面是配置文件、日志和 OCR 临时文件）。

------------------------------------------------------------------------
十一、本版新增能力与优化迭代（v1.2）
------------------------------------------------------------------------
1. 每次点击后都强制识别校验
   每一次模拟点击之后，程序都会立即截图 + OCR + 解析，并在日志里打印
   “点击后校验（识别完成）：…”。如果点击后页面没有按预期变化，
   程序会立即换一种方式重试，而不是傻等超时。
   日志示例：
       点击「底部「下一节」按钮」，第 3 次点击
       点击后校验（识别完成）：章节=现代国防观 | 播放状态=unknown
       「下一节」按钮暂未生效，改为点击目录中的下一节

2. “真的在播放”三重判定（修复“中央播放键误判”问题）
   新版本不再只看某个按钮就认为在播放，而是同时检查：
       · 连续抓 3 帧，比较视频画面区域的变化比例（画面在动 = 在播放）；
       · 视频中央是否存在“灰色圆盘 + 白色三角”的大播放按钮
         （存在 = 还没开始播放，即使识别到“播放键”也不算在播）；
       · 控制条上的图标是“暂停键”还是“播放键”。
   只有确认“真的在播”，程序才开始抖动鼠标和监控进度；
   否则会在“点击 → 识别校验 → 再点击”的循环里纠正，最多尝试 6 次。

3. 断点续播
   程序会把“当前进行到哪一节、完成了哪些节”记录到
   %LOCALAPPDATA%\XxtAutoPlay\resume.json。
   下次双击 exe 时会自动接上上次的章节继续播；
   想强制从页面当前章节开始，用：学习通自动播放.exe --reset-resume

4. 失败降级链与自动重试
   切下一节时按「下一节按钮 → 目录下一行 → 目录向下滚动 → 再试按钮」
   的顺序自动降级；点击失败会重试，仍失败则记录日志继续下一节，
   不会整段卡死。

5. 性能分层（降低 CPU 占用）
   高频轮询只用像素级分析（毫秒级）；完整 OCR 默认 7 秒一次，
   并且同一画面会复用识别结果，避免重复计算。

以上 1/2/3/4/5 均已实现在本版本中。后续还可以继续迭代的方向（供参考）：
   · 多模板/多分辨率适配（换电脑、换缩放比例时更稳）；
   · 把“弹题”题目截出来做 OCR 后通过可配置题库自动作答；
   · 播放异常时自动刷新页面并从断点续播；
   · 托盘图标 + 全局快捷键（F9 暂停 / F10 继续）；
   · 运行报告（每节实际观看时长、完成比例）导出 CSV。
